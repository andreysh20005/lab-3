## Задача 1

### Текст задачи

Решить задачу из лабораторной работы №2 (Задание 1. List.map) для
последовательности
(На основе данного списка строк получить новый, где к каждой строке в конце
дописан заданный символ)

### Алгоритм решения

После этого запрашиваются строки (поскольку это sequence, т.е. отложенные вычисления, порядок вызовов будет именно такой, не смотря на порядок вызова функций и то, что sequence объявлено раньше, чем символ. Sequence заполняется значениями только в момент их использования). К полученному набору строк (к каждой строке) применяется функция добавления символа (через Seq.map). полученный набор строк выводится пользователю

## Задача 2

### Текст задачи

Решить задачу из лабораторной работы №2 (Задание 2. List.fold) для
последовательности
(Список содержит строки. Найти самую короткую строку)
### Алгоритм решения

полььзователь вводит число - количество элементов sequence. Далее у него n+1 раз запрашивается строка (это является особенностью заполнения sequence через генератор, поскольку идёт заполнение сначала "головы", а потом "хвоста" sequence - из-за отложенного заполнения происходит 2 вызова генератора, но первый вызов только для одного элемента (head), при этом второй вызов (tail) идёт от 1 до n). У полученных строк сравнивается длинна через Seq.fold. аккумулятором выступает первый элемент sequence (head), далее идёт сравнение длин строк (через функцию minimumLenth, которая возвращает строку минимальной длинны. Полученная строка и её длинна выводятся пользователю
