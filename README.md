## Задача 1

### Текст задачи

Решить задачу из лабораторной работы №2 (Задание 1. List.map) для
последовательности
(На основе данного списка строк получить новый, где к каждой строке в конце
дописан заданный символ)

### Алгоритм решения

первое число n - число элементов sequence. далее запрашивается символ, который будет добавлен. После этого запрашиваются строки (поскольку это sequence, т.е. отложенные вычисления, порядок вызовов будет именно такой, не смотря на порядок вызова функций и то, что sequence объявлено раньше, чем символ. Sequence заполняется значениями только в момент их использования). К полученному набору строк (к каждой строке) применяется функция добавления символа (через Seq.map). полученный набор строк выводится пользователю

## Задача 2

### Текст задачи

Решить задачу из лабораторной работы №2 (Задание 2. List.fold) для
последовательности

### Алгоритм решения
